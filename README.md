# Portfolio Personal

Este proyecto es un portfolio web estático diseñado para presentar mi perfil profesional, experiencia, habilidades, proyectos y medios de contacto de forma clara y visual.

La página está construida con HTML y CSS, con un diseño moderno y adaptable para diferentes tamaños de pantalla.

## ¿Qué incluye?

- Presentación personal con nombre, profesión y enlaces sociales
- Sección de formación y educación
- Sección de habilidades técnicas y profesionales
- Experiencia laboral y trayectoria
- Portafolio de proyectos
- Formulario de contacto integrado con Formspree
- Descarga de CV en español e inglés
- Diseño responsivo para móvil, tablet y escritorio

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript básico para navegación móvil
- Font Awesome para iconos
- Formspree para el envío de mensajes del formulario

## Estructura del proyecto

- `index.html` — estructura principal del sitio
- `css/style.css` — estilos principales del portfolio
- `css/general.css` — estilos generales y utilidades
- `img/` — imágenes, logos y recursos visuales
- `docs/` — archivos PDF del CV

## Cómo ejecutar el proyecto

Como es un sitio estático, puedes abrir directamente el archivo `index.html` en tu navegador.

Si prefieres servirlo localmente desde un servidor web, puedes ejecutar:

```bash
python -m http.server 8000
```

Luego abre en tu navegador:

```text
http://localhost:8000
```

## Cómo personalizarlo

Puedes adaptar fácilmente este portfolio para tu propio perfil:

1. Cambia el nombre, título profesional y textos principales en `index.html`.
2. Actualiza los enlaces a LinkedIn, GitHub y CV.
3. Modifica las secciones de educación, experiencia y proyectos.
4. Sustituye imágenes, logos y fotos en la carpeta `img/`.
5. Ajusta el diseño y colores en los archivos CSS dentro de `css/`.

## Contacto

El formulario de contacto está listo para enviar mensajes a través de Formspree. Si quieres usarlo con tu propia cuenta, cambia la acción del formulario en `index.html`.

## Objetivo del proyecto

Este portfolio sirve como carta de presentación profesional online, mostrando tanto la parte técnica como la experiencia de liderazgo y gestión, reflejando un perfil híbrido entre desarrollo backend y visión de negocio.
